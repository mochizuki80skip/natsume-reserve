## 記述問題の採点基準（各 2 点）

採点：下の「必須ポイント」をすべて押さえていれば 2 点、半分以上なら 1 点、それ未満は 0 点。
「法律や社内ルールに反する対応を肯定している」記述（例：保健所の届出をせずに保険請求を始める、退職を認めない）は、他のポイントがあっても 0 点。

### A3-K1（新しい柔道整復師の勤務開始まで）

必須ポイント
1. 保健所に「施術所開設届出事項変更届」を出す（持ち物：免許原本と A4 コピー、変更届の提出用と A4 コピー、本人の運転免許証。静岡市内は本人同伴。必要書類は事前に保健所へ確認）
2. 提出用と免許コピーを保健所に提出し、控えに受付印をもらう → 控えと免許コピーをレセコンに FAX し、電話で届いたか確認 → 事務所に PDF 送信＆郵送
3. 登録が済むまでは保険請求できない（登録ミスは保険請求できない原因・本人の将来に影響）ことを理解し、勤務開始前に完了させる
4. 社内手続き：勤務開始日が決まった当日に人事変更報告書を PDF で事務所へ、スクラブ等の発注・名札作成、勤務初日に雇用開始時必要書類の確認と PDF 送信

### A3-K2（退職の申し出）

必須ポイント
1. 当日：MG に報告（MG から事業長へ）
2. 退職日の 3 週間〜1 か月前までに、退職届・退職届受理後の手続き（本人記入→院長確認）・人事変更報告書の 3 点を事務所に PDF 送信
3. 退職日当日：資格確認書等・経営計画手帳・クレド・制服の返還を受ける、勤怠の備考欄に退職日を記載、MG に退職日と氏名をメール報告、解析表の離職者欄
4. その後：返還物の事務所への郵送、（柔道整復師なら）保健所への変更届（理由「退職」）
5. （加点要素）申し出を拒否・引き止め続けない（法律上は申入れから 2 週間で退職できる）、離職票の要否を確認する

※ 1〜4 で 2 点。「来月末」は社内目安の 3 か月前より短いが、退職を認めないとする記述は 0 点。

### A3-K3（週報の未達理由・行動変化の指導）

必須ポイント
1. 未達理由を定量的に：予定と実績の数字（例：紹介依頼を〇人に予定し△人しかできなかった）と「なぜならば」を深掘りした原因（対象者のリストアップがない・声かけの担当やタイミングが決まっていない 等）
2. 行動変化を定量的に：いつ（期限）・だれが・何を・どのくらい（数値）・どのように行う、を入れる（例：〇日までに対象者を〇人リストアップし、〇日から 1 日〇人に声かけ）
3. 目標との差（7 人）を埋める計画になっているか確認する
4. 書き直しは週報の期限（締め日当日 23:00）を守る／MG から再提出の指示があれば再提出欄に書く

### A3-K4（受付の残業が多く理由の記載がない）

必須ポイント
1. スタッフに、残業がある日は備考欄に残業理由を書くルールを指導する（毎日打ち込み・保存も確認）
2. 院長は勤怠の管理者として残業時間をコントロールする責任がある（日報の解析表の残業時間・勤怠の時間外を確認）
3. 原因を確認し、締め作業の手順・人員配置・シフトを見直して残業を減らす
4. 残業の実態は正しく記録させる（記録を減らさせる・サービス残業にするのは不可）。必要に応じて MG に相談する
