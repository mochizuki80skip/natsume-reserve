## 記述問題の採点基準（各 2 点）

採点：下の「必須ポイント」をすべて押さえていれば 2 点、半分以上なら 1 点、それ未満は 0 点。
「不正になる対応を肯定している」記述は、他のポイントがあっても 0 点。

### B3-K1（慢性腰痛の常連患者を保険で）

必須ポイント
1. スタッフを止める：事実と違う負傷原因を書くのは振替請求（不正）であると指導する
2. 患者様に確認：新たな負傷（いつ・どこで・何をして・どうなった）があるか聞く
3. なければ保険の対象外であることを説明し、自費の同意を得る（施術前）
4. 再発防止：受付手順・問診票の確認をスタッフ全体に周知する

### B3-K2（照会を書いておいてと頼まれた）

必須ポイント
1. スタッフが代筆しない・回答内容を誘導しない
2. 照会の目的（保険者の通常の確認）を説明し、本人が事実どおりに・期限内に回答するようお願いする
3. 書き方（どの欄に何を書くか）の質問には答えてよい
4. 回答しないと支給が保留・不支給になりうることを伝える

### B3-K3（一括打ち切り後に健保で続けたい）

必須ポイント
1. 交通事故でも健康保険は使えるが、患者様から保険者へ「第三者行為による傷病届」の提出が必要
2. 申請書の負傷原因に交通事故であることを書く（日常のケガとして請求しない）
3. 同じ期間・同じ負傷を自賠責と健保に二重請求しない（切替日を明確にする）
4. 仕事中・通勤中の事故なら健保は使えない（労災または自賠責）
5. （加点要素）一括対応の終了＝治療の終了ではないこと、自賠責への被害者請求という選択肢もあること、窓口負担が発生することを説明する（C 分野と関連）

※ 1〜4 で 2 点。

### B3-K4（資格喪失の返戻が毎月続く）

必須ポイント
1. 原因：毎月最初の来院時の資格確認ができていない（声かけ・確認漏れ）、転職・退職・75 歳到達などを把握していない
2. 対策：毎月初回の資格確認と声かけの徹底、70 歳・75 歳到達者の把握
3. 返戻分は新しい保険を確認して請求し直す
4. 返戻を理由別に記録して改善を確認する
