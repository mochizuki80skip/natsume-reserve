## 記述問題の採点基準（各 2 点）

採点：「必須ポイント」をすべて押さえていれば 2 点、半分以上なら 1 点、それ未満は 0 点。
**不正になる対応（来院日・部位の水増し、症状のない部位の申告を促す、示談・過失割合の交渉を院が行う）を肯定している記述は、他のポイントがあっても 0 点。**

### C3-K1（一括対応の終了の通告）

必須ポイント
1. 施術録で症状・経過（改善傾向だが残存）を確認し、保険会社に具体的に説明する
2. 患者様に整形外科を受診してもらい、医師の意見（治療継続の必要性）を確認する
3. 一括終了は治療の終了ではないことを患者様に説明し、選択肢（被害者請求・健保〔第三者行為の届出〕・人身傷害・弁護士相談）を示す。決めるのは患者様
4. やり取りの記録（日時・担当者・内容）を残し、重要事項は書面でも確認する

### C3-K2（医師の同意がないと払えない）

必須ポイント
1. 打撲・捻挫の施術に法律上医師の同意は不要であることを理解している
2. ただし医師の診断・指示が施術の必要性の裏づけになるため、患者様に整形外科の定期的な受診（併院）をすすめる
3. 患者様から医師に接骨院への通院を伝えてもらう
4. 解決しない場合は MG・交通事故責任者に相談し、患者様に被害者請求などの選択肢を説明する

### C3-K3（過失 80％で健保対応と言われた）

必須ポイント
1. 患者様の過失が 100％でない限り、相手の自賠責に被害者請求できる
2. 過失 70％以上のため傷害は 2 割減額（120 万円の枠は実質 96 万円まで）
3. 健康保険を使う場合は第三者行為による傷病届が必要で、窓口負担が出ること。人身傷害保険の有無も確認
4. 院は過失割合・示談の交渉をしない。選択肢を説明し、決めるのは患者様

### C3-K4（症状のない腰の診断を勧めた）

必須ポイント
1. スタッフの発言をすぐに止め、症状のない部位の申告を促すことは不正（保険金詐欺のおそれ）であると指導する
2. 患者様に誤った案内だったことを説明し、症状のない部位は申告・請求しないことを伝える
3. 本当に腰の症状がないか改めて確認し、症状があれば医師に伝えるよう案内するのは正しい対応であることを区別する
4. 再発防止：院内全体に周知し、MG・本部に報告する
