# B2 健康保険業務（中級）マニュアル

対象：B1 合格者　／　到達目標：申請書を自分で正しく作れ、返戻・照会・労災・公費などのイレギュラーを正しく処理できる

> 【公的制度】＝法律・通知の決まり、【社内方針】＝当社の決まり、【要確認】＝改定で変わるため本部が最新を確認する箇所、【要記入】＝本部が社内の情報を記入する箇所

---

## 1. 申請書（療養費支給申請書）の記載

### 1-1 記載項目の基本【公的制度】

| 項目 | ポイント |
|---|---|
| 被保険者・患者の情報 | 資格確認した内容と一致させる（記号・番号・氏名・生年月日・負担割合） |
| 負傷名 | 部位＋負傷名（例：右足関節捻挫、腰部挫傷）。左右を必ず書く |
| 負傷年月日・初検日・施術開始日・終了日 | 負傷日は問診で聞いた日。初検日は最初に施術した日 |
| 転帰 | 治癒・中止・転医 など |
| 施術日 | 実際に施術した日だけ |
| 負傷の原因 | 「いつ・どこで・何をして・どうなった」を具体的に（下記） |
| 委任欄 | 患者様本人の署名（B1 6 章） |

### 1-2 負傷原因の書き方【公的制度】【要確認】

- 3 部位以上を請求する場合などには、部位ごとの負傷原因の記載が求められる（現在の記載ルールは本部の最新版に従う）。
- **悪い例**：「日常生活で負傷」「スポーツ中に負傷」
- **良い例**：「10 月 3 日、自宅の階段を降りる際に最後の一段を踏み外し、右足首を内側にひねって負傷」

### 1-3 部位数と逓減【公的制度】【要確認】

- 同時に施術した部位は、料金を算定できるのは原則 **3 部位まで**。3 部位目は所定料金を減額（逓減）して算定し、4 部位目以降は算定しない。
- 同じ部位を負傷から長期間施術している場合、一定期間（初検から 5 か月超 など）を超えると料金が逓減される。
- 具体的な料金・割合は療養費の改定（概ね 2 年ごと）で変わるため、本部配布の最新料金表で確認する。

### 1-4 長期・頻回の理由【公的制度】【要確認】

- 初検日から **3 か月を超えて** 施術を続ける部位は、申請書に「長期施術継続理由」を書く。
- 1 か月の施術回数が多い場合（基準の回数は最新ルールで確認）は、その理由の記載が求められる。
- 理由は「まだ痛みがあるため」だけでは不十分。症状の経過・施術の必要性を具体的に書く。

### 1-5 してはいけない書き方【公的制度】

| 不正の種類 | 内容 |
|---|---|
| 架空請求 | 来ていない患者・日の請求 |
| 付増請求 | 施術日数・部位数を実際より多く書く |
| 振替請求 | 慢性症状や自費の施術を外傷として書く |
| 部位転がし | 長期・逓減を避けるため、負傷部位を次々入れ替える |

## 2. 月末の請求事務

### 2-1 流れ【社内方針】【要記入】

1. 月末に当月分の施術日・部位・負傷原因・署名の漏れを確認する
2. レセコンで申請書を作成・印刷（または電子データ作成）
3. 院長（施術管理者）が内容を確認して押印・サイン
4. 提出先：【要記入】（保険者・柔整師会・請求代行など）
5. 提出期限：【要記入】（例：翌月○日必着）
6. 提出控えを保管

### 2-2 よくあるミス

- 月の途中で保険が変わったのに旧保険のまま請求
- 署名漏れ
- 負傷日より前の日付で施術日を記載
- 負担割合の誤り（70 歳・75 歳の誕生日をまたぐ月に注意）

## 3. 返戻と患者照会

### 3-1 返戻（へんれい）【公的制度】

保険者が申請書を受け付けず、施術所に差し戻すこと。主な理由：

- 資格喪失（保険が変わっていた）
- 記載不備（負傷原因・長期理由・署名・番号の誤りなど）
- 照会への回答がない・内容が合わない
- 同じ期間に病院で同じ負傷の治療を受けていた

### 3-2 返戻への対応【社内方針】

1. 返戻理由を確認し、院長に報告
2. 資格喪失 → 患者様に新しい保険を確認し、新しい保険者に請求し直す（必要なら患者様から差額を精算）
3. 記載不備 → 正しく直して再請求（事実と違うことを書き足さない）
4. 返戻の件数・理由を記録（本部への報告：【要記入】）

### 3-3 患者照会【公的制度】

- 保険者が、患者様本人に文書で「いつ・どこで・どうして負傷したか」「何日通ったか」などを確認すること。
- 回答がないと、支給が保留・不支給になることがある。

### 3-4 照会への対応【社内方針】

- 患者様に照会の目的を説明し、**期限内に、事実どおりに** 回答するようお願いする。
- 書き方の質問（どの欄に何を書くか）には答えてよい。
- **スタッフが代わりに記入する・回答内容を誘導する・申請書と合わせるよう指示することは禁止**。
- 回答内容と申請書が違っていた場合は、事実に合わせる（申請書を事実に合わせて訂正する）。

## 4. 労災保険

### 4-1 労災の対象【公的制度】

- **業務災害**：仕事中のケガ
- **通勤災害**：通勤途中のケガ（合理的な経路・方法での移動中）
- 労災の対象となるケガに **健康保険は使えない**。

### 4-2 柔道整復の労災請求【公的制度】【要確認】

- 柔道整復師用の請求書を使う（業務災害・通勤災害で様式が違う。現在の様式番号は本部で確認）。
- 請求書には **事業主の証明**（会社の証明欄）が必要。
- 請求先は労働基準監督署（都道府県労働局）。施術所が患者様に代わって受け取る手続きをとる。
- 業務災害は原則として患者様の窓口負担なし。

### 4-3 受付での対応【社内方針】

1. 仕事中・通勤中と分かったら健保で受け付けない
2. 患者様に「勤務先に労災の手続きをお願いします」と伝え、請求書の事業主証明をもらってきてもらう
3. 書類がそろうまでの窓口対応：【要記入】（例：預り金の扱い）
4. 健保で受けた後で労災と分かった場合 → 院長に報告。保険者への返還と労災への切替手続きが必要

## 5. 生活保護・公費・高齢者

### 5-1 生活保護（医療扶助）【公的制度】【要確認】

- 生活保護の方の施術は、福祉事務所が発行する **施術券** にもとづいて行う（施術所は指定施術機関であることが必要）。
- 施術券は月ごと。施術券がない状態で施術した分は原則請求できないため、来院時に福祉事務所へ確認する。
- 骨折・脱臼の施術は医師の同意が必要（健保と同じ）。
- 原則、患者様の窓口負担はない（本人支払額が決められている場合を除く）。

### 5-2 公費（医療費助成）【公的制度】【要確認】

- 子ども医療費、ひとり親家庭、重度障害者などの助成は **市町ごとに対象年齢・自己負担額・接骨院での取扱い（窓口で使えるか、償還払いか）が違う**。
- 店舗がある市町の取扱い：【要記入】（静岡県内の各市町の一覧を本部で作成）
- 受給者証の有効期限・所得区分を確認する。

### 5-3 高齢者【公的制度】【要確認】

- 70〜74 歳：2 割（現役並み所得は 3 割）。誕生月の翌月（1 日生まれはその月）から変わる。
- 75 歳到達で後期高齢者医療に移行。誕生日当日から保険者が変わるため、月の途中で保険が変わる。
- 後期高齢者の負担割合（1 割・2 割・3 割）は資格確認で毎回確認する。

## 6. 交通事故で健康保険を使う場合

### 6-1 使えるのか【公的制度】

- 交通事故のケガでも健康保険は使える。ただし、保険者への **「第三者行為による傷病届」** の提出が必要（患者様が提出）。
- 保険者は、立て替えた医療費をあとで加害者側（保険会社）に請求する（求償）。

### 6-2 使うときの注意【公的制度＋社内方針】

- 申請書の負傷原因に交通事故であることを書く。事故を隠して日常のケガとして請求するのは不正。
- **同じ期間・同じ負傷を、自賠責と健保の両方に請求しない**（二重請求）。
- 仕事中・通勤中の交通事故は **労災が優先**。
- 自賠から健保に切り替える場合・健保を使う場合は、院長が判断し、患者様に違い（窓口負担・慰謝料などへの影響）を説明する（詳しくは C 分野）。

## 7. まとめ（中級で必ず覚えること）

1. 負傷原因は「いつ・どこで・何をして・どうなった」を具体的に。
2. 3 部位目以降の逓減、長期の逓減、長期・頻回の理由記載。最新の料金・回数は本部の料金表で確認。
3. 架空・付増・振替・部位転がしは不正請求。
4. 返戻は理由を確認して正しく直す。照会は患者様が事実どおりに回答。代筆・誘導は禁止。
5. 仕事中・通勤中は労災。事業主証明が必要。
6. 生活保護は施術券、公費は市町ごとの取扱いを確認。
7. 交通事故で健保を使うときは「第三者行為による傷病届」。自賠と二重請求しない。
