# A1 管理業務（下級）マニュアル

対象：全スタッフ　／　到達目標：会議・勤怠・社内提出物の基本ルールを知っていて、自分の分を間違えずに実行できる

> 【公的制度】＝法律の決まり、【社内方針】＝当社の決まり、【要確認】＝変わりやすい／資料が古いため本部が最新を確認する箇所、【要記入】＝本部が社内の情報を記入する箇所
> 管理業務の分野は、ほとんどが【社内方針】です。ファイル名・保存場所・提出先は人事異動やシステム変更で変わるため、最新は院長・MG に確認してください。

## 1. 会議・研修のルール

### 1-1 会議・研修・プロジェクトの違い【社内方針】

| | 会議 | 研修 | プロジェクト |
|---|---|---|---|
| 条件 | **目的・議題がある** こと。目的や議題がなく、ただ集まって話すものは会議ではない | 業務に必要な **知識や技術を学ぶ場** | **目的がある** こと（独自の製品・サービス・成果をつくるために行う） |
| もう一つの条件 | **意思決定がされる** こと。目的・議題についての話し合いの中で、何かが決まる必要がある | 人材育成・自己成長の場として使う | **期限がある** こと（有期性） |

### 1-2 参加するときのルール【社内方針】

- **5 分前行動** を原則とする。
- 集合して行う会議・研修：**5 分前に着席**、**3 分前には開始準備を終わらせる**。
- Web（ZOOM）の会議・研修：**5 分前に着席**し、ネット環境を確認、**3 分前には入室申し込み** をする。
- 参加者がそろわなくても **定刻に開始** する。
- **開始時間だけでなく終了時間も決めておく**。

### 1-3 遅刻・欠席の連絡【社内方針】

- 事情により急に欠席・遅刻する場合は、会議・研修の責任者、または会議・研修に参加する上長に、**会議開始 15 分前までに電話** で連絡する。
- LINE やメールを送っただけで済ませない（電話で伝える）。
- 管理者研修（院長・管理者向け）は連絡の方法が別に決まっている（A3 で学ぶ）【要確認】。

### 1-4 スタッフが参加する主な会議・研修【社内方針】【要確認】

| 名称 | 参加者 | 開催の目安 |
|---|---|---|
| 全体会議 | 全従業員 | 月 1 回（第三木曜日の午前）【要確認】 |
| スタッフ研修 | 院長以外の柔道整復師 | 月 1 回（夜）【要確認】 |
| 受付研修 | 正社員の受付 | 月 1 回（昼）【要確認】 |

- 日時は変わることがあるため、院のカレンダーで確認する。院長はスタッフの会議日もカレンダーで管理している。

## 2. 姿勢のルール（毎日の基本）【社内方針】

会社全体の「姿勢のルール」と、各院の「姿勢のルール」がある。**各院のルールも必ず確認する**（出勤時刻・朝の準備などは院によって違う）。

| 場面 | 全体のルール |
|---|---|
| 出勤 | 自分の決められた出勤時間に間に合うように出勤する。朝礼には仕事ができる服装で参加する（身だしなみチェックシート参照） |
| 朝礼 | **営業開始 15 分前に開始**。理念唱和をする |
| 営業 | 各院の指定の時刻に開始し、最後の患者様のお帰りをもって終了 |
| 昼休み | 院の外に出るときは **上下とも着替える**（白衣・スクラブのまま外に出ない） |
| 入金作業 | 昼の入金作業は決められた時刻（14:30 など）までに行う。就労時間を超えて入金した人は勤怠に加算して記録する（加算の方法は各院ルール）【要確認】 |
| 締め作業 | 各院指定の締め作業を行い、速やかに帰宅する |

## 3. 自分の勤怠

### 3-1 毎日打ち込む【社内方針】

1. 院のサーバー（院のフォルダ）を開く
2. 「勤怠」フォルダを開く
3. 「〇〇接骨院勤怠 20XX 年〇月度」を開く
4. 自分のシートに勤怠を打ち込む

- **勤怠は毎日打ち込み、その都度保存する**（まとめて月末に入力しない）。
- 出社・休憩・退社の時刻を入れると、労働時間・時間内・時間外は自動で計算される（計算のセルは触らない）。

### 3-2 勤怠表の記号【社内方針】

| 記号 | 使うとき |
|---|---|
| ○ | 出勤 |
| 欠 | 欠勤 |
| 前欠／後欠 | 午前のみ欠勤／午後のみ欠勤（半休扱い）。※遅刻は半休扱いとされている【要確認】 |
| 定 | 定休日（院の定休日。例：日曜・木曜・祝日）【要確認】 |
| 有 | 有給休暇（1 日） |
| 前有／後有 | 午前のみ有給／午後のみ有給（半日有給） |
| 計 | 計画有給（日付は労使協定書を確認） |
| MT | ミーティング・会議などで出勤した日（時間を記入） |
| 他休 | その他の休暇（育休・産休・休業など）。備考欄に理由 |
| 出 | 出張（出勤扱い）：会社指示・会社都合の勉強会・管理者研修・講習。備考欄に理由、時間は定時を記入 |

### 3-3 有給の日の時間の入れ方【社内方針】

| | 正社員 | パート |
|---|---|---|
| 1 日有給（「有」） | **時間は入れない**（出勤していないため） | **雇用契約どおりの時間を入れる**（時給のため、出勤していなくても給与が発生する時間が必要） |
| 半日有給（「前有」「後有」） | **出勤した時間を入れる** | **雇用契約どおりの時間を入れる** |

### 3-4 備考欄に書くこと【社内方針】

| その日 | 備考欄 |
|---|---|
| 残業がある日 | **残業理由**（例：締め作業） |
| 欠勤した日 | **欠勤理由**（例：体調不良の為欠勤） |
| 有給の日 | **「有給」** と記載 |

### 3-5 全体会議の日の書き方（職種で違う）【社内方針】【要確認】

| | 書き方 | 理由 |
|---|---|---|
| **受付・パートさん** | 「MT」にチェックし、**備考欄に「9:00―12:00 3H」のように時間を記載**。**実働の欄には何も打ち込まない** | 会議の時間を本部で別に計算するため |
| **先生（柔道整復師）** | 「MT」にチェックし、**実働の欄に打ち込む** | 先生の給与には残業手当が最初から含まれているため |

## 4. 有給休暇（有給届）

### 4-1 有給休暇とは【公的制度】

- 年次有給休暇は、一定期間勤務した従業員に法律（労働基準法）で認められた休暇で、休んでも給与が支払われる。

### 4-2 当社の申請ルール【社内方針】

- 有給は **基本的に事前申請** で認められる。休みたい日が決まったら、早めに「有給休暇取得申請書」を書いて院長に渡す。
- 申請書は院のサーバー（雇用関係の事務所申告書の書類）にある。所属する法人の書式を使う（法人によって書式が違う）。
- **半日の場合は「0.5 日」と記載** する。
- 院長は預かった申請書を、**10 日・20 日の事務所送付のうち近い方** に同封して事務所に送る（A2）。
- 勤怠表にも「有」「前有」「後有」を正しく入れる（3-2・3-3）。
- 病気などで当日に休んだ場合の扱い（事後の申請を認めるか）、申請理由の書き方は本部に確認【要確認】。

## 5. 事務所に出す申告書類（自分のこと）

### 5-1 書類の種類と使うとき【社内方針】

書式は「接骨院事業部 リンク」→「業務チェックシート」から開ける（所属法人の書式を選ぶ）。
**年金・保健所・労災などの手続きに必要なので、変更があれば必ず提出する。**

| 書類 | 使うとき | ポイント |
|---|---|---|
| 身上変更届 | 結婚・出産などで **扶養者に変更** があるとき | |
| 住所等変更届 | **住所が変わった** とき | 通勤申告書も新しい住所で出す |
| 通勤申告書 | 入社時・**住所変更時**・通勤経路が変わったとき | 住所等変更届も出す。**提出した翌月から** 通勤手当が変わる |
| 給与振込口座依頼書 | **給与の振込先を変える** とき | **毎月 10 日までに** 届けば、その月末の給与から振込先が変わる |
| 慶弔見舞金支給申告書 | 結婚祝金・家族弔慰金・出産祝い金・災害見舞金の申請 | 内容は就業規則を参照 |
| 有給休暇取得申請書 | 有給を取るとき | 4 章 |

（人事変更報告書は採用・退職・異動などを院長が報告する書類。A3 で学ぶ）

### 5-2 通勤申告書の書き方【社内方針】

1. 「新規」か「変更」に○
2. 日付：記入日
3. 所属：院名
4. 氏名
5. 通勤距離（片道の実際の距離）
6. 通勤手段
7. **Google マップの経路検索の画面をスクリーンショットして印刷し、添付** する

- 通勤手当の金額（距離による区分・正社員は月額／パートは日額）は書式に書かれている【要確認】。

## 6. ファイル・スプレッドシートの入力ルール【社内方針】

| ルール | 内容 |
|---|---|
| 数字は **半角** | すべてのシートで、数字は半角で打ち込む（全角だと計算されない） |
| **関数のセルは触らない** | 合計・平均などの計算式が入ったセルは、消したり上書きしたりしない |
| **入力を指定された所以外は触らない** | 分からないセルに入力しない。迷ったら院長に確認 |
| 色の意味はファイルごとに確認 | 日報の Excel では **黄色＝関数（触らない）**。一方、Google スプレッドシートの目標・週報では **黄色＝入力する所** とされている【要確認】。色だけで判断せず、院長に「どこに入力するか」を確認する |
| 保存 | 打ち込んだらその都度保存する |

### 6-1 院のスプレッドシートに毎日打ち込むもの【社内方針】

1. 個別離反（担当患者様の離反）
2. 離反対策（電話）
3. 新患継続率・再来継続率
4. その他、エリアで決めた行動

## 7. 大掃除【社内方針】

- **大掃除の定義**：日々の清掃業務の範囲を超えた、大規模な清掃。
- 年末などの最終診療日に行う。

手順

1. 各院の「業務チェックリスト」を開く
2. 「大掃除の定義」を確認する
3. **最終診療日掃除チェックシート** の項目（玄関タイル・看板・ポスト・蜘蛛の巣・外壁・エアコン・ダンボールのゴミ など）を確認し、チェック（✅）を入れる
4. シート下の **備考欄に報告事項を記入**（例：車止め一部破損 … MG 報告済み）
5. チェック後、**MG へ 19 時までに報告**（LINE）

## 8. まとめ（下級で必ず覚えること）

1. 会議は「目的・議題」と「意思決定」、研修は「学ぶ場」、プロジェクトは「目的」と「期限」。
2. 5 分前行動。集合は 5 分前着席・3 分前準備完了、Web は 5 分前着席・3 分前入室。定刻に開始。
3. 急な遅刻・欠席は **開始 15 分前までに電話** で責任者・上長へ。
4. 勤怠は **毎日打ち込み、その都度保存**。備考欄に残業理由・欠勤理由・「有給」。
5. 全体会議の日：受付・パートは備考欄に時間を書き実働は空欄、先生は実働に打ち込む。
6. 有給は事前申請。半日は 0.5 日。院長が 10 日・20 日の近い方で事務所へ送る。
7. 住所が変わったら住所等変更届と通勤申告書（Google マップの経路を添付）。
8. 数字は半角。関数のセル・指定以外のセルは触らない。
9. 大掃除はチェックシートに✅、備考欄に記入、MG へ 19 時までに報告。
