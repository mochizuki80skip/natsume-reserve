# C2 交通事故対応業務（中級）マニュアル

対象：C1 合格者　／　到達目標：交通事故の請求業務を正しく行い、保険会社と記録にもとづいてやり取りでき、患者様に選択肢を正しく説明できる

> 【公的制度】＝法律・保険の決まり、【社内方針】＝当社の決まり、【要確認】＝改定で変わるため本部が最新を確認する箇所、【要記入】＝本部が社内の情報を記入する箇所

---

## 1. 請求の方法は 3 つ

| 方法 | 誰が・どこに | 特徴 |
|---|---|---|
| **任意一括対応** | 任意保険会社が、自賠責の分も含めて施術費を支払う | 患者様の窓口負担なし。接骨院は任意保険会社に請求する。いちばん多い |
| **被害者請求**（自賠法 16 条） | 患者様（被害者）が、加害者の **自賠責保険に直接** 請求する | 任意保険会社が一括対応しない・打ち切った場合でも、自賠責の枠（120 万円）の範囲で請求できる |
| **加害者請求**（自賠法 15 条） | 加害者が被害者に払った後、自賠責に請求する | 接骨院が関わることは少ない |

### 1-1 仮渡金（かりわたしきん）【公的制度】【要確認】

- 被害者請求では、当座の費用として仮渡金を受け取れる（ケガの程度により 5 万円・20 万円・40 万円）。

### 1-2 時効【公的制度】【要確認】

- 自賠責への被害者請求の時効は、傷害は **事故日から 3 年**、後遺障害は **症状固定日から 3 年**。

## 2. 請求業務（任意一括対応の場合）

### 2-1 初診から請求までの流れ【社内方針】【要記入】

1. 初診：問診（C1 4-2）、相手の保険会社に連絡（院長）。施術開始の連絡と、請求先・担当者を確認
2. 患者様から保険会社へ **同意書**（医療照会・施術費の支払いに関する同意書）を出してもらう
3. 毎月：**施術証明書・施術費明細書** を作成し、保険会社へ送付（締め日・送付期限：【要記入】）
4. 施術録に、毎回の症状・施術内容・経過を記録する
5. 保険会社からの医療照会・経過の問い合わせに、施術録にもとづいて回答する

### 2-2 施術料金【公的制度】【社内方針】【要確認】

- 自賠責の支払基準では、柔道整復の施術費は **「必要かつ妥当な実費」**。健康保険の料金表どおりである必要はない。
- 当社の交通事故の施術料金基準：【要記入】（本部で確認・統一する）
- 料金の根拠（施術内容・部位・回数）は施術録で説明できるようにしておく。

### 2-3 書類で気をつけること【社内方針】

- 施術日・部位は **施術録と一致** させる。来院していない日・施術していない部位を書かない。
- 部位は、問診・医師の診断・施術録の記録にもとづくものだけ。

## 3. 過失割合と自賠責

### 3-1 自賠責は過失があっても使える【公的制度】

- 自賠責保険は被害者救済のための保険なので、患者様に過失があっても、**相手の自賠責に請求できる**。
- 例：患者様の過失 80％・相手の過失 20％ の事故でも、患者様は相手の自賠責に請求できる（下記の減額あり）。
- ただし、**相手に過失がまったくない（患者様の過失 100％）場合は、相手の自賠責から支払われない**。

### 3-2 重過失減額【公的制度】【要確認】

| 患者様（被害者）の過失 | 傷害の減額 |
|---|---|
| 70％未満 | 減額なし |
| 70％以上 100％未満 | 2 割減額（120 万円の枠なら実質 96 万円まで） |

### 3-3 「健保対応でお願いします」と言われたとき【公的制度】【社内方針】

- 患者様の過失が大きい場合、任意保険会社から「健康保険を使ってほしい」と言われることがある。
- 健康保険の使用を求められても、患者様に過失 100％でない限り、**相手の自賠責への被害者請求という選択肢がある**。
- どの方法がよいかは患者様の状況（過失割合・窓口負担・慰謝料・人身傷害保険の有無）で変わる。院長が選択肢を説明し、**患者様が決める**。
- 保険会社に交渉・依頼をするのは施術費の支払い方法についてまで。過失割合や示談の交渉はしない（C3）。

## 4. 健康保険・労災・人身傷害保険

| 場面 | 使える保険 | 注意 |
|---|---|---|
| 一括対応がない・打ち切られた | 被害者請求／健康保険（第三者行為による傷病届）／患者様の人身傷害保険 | 健保に切り替えると窓口負担が出る |
| 仕事中・通勤中の事故 | 労災保険または自賠責 | 健康保険は使えない。どちらを先に使うかは労基署・保険会社と確認【要確認】 |
| 患者様の過失が大きい | 相手の自賠責（減額あり）／健康保険／人身傷害保険 | 3-3 のとおり選択肢を説明 |

- 同じ期間・同じ負傷を、自賠責と健保の両方に請求しない（B2 6-2）。

## 5. 保険会社とのやり取りの基本

### 5-1 ルール【社内方針】

| ルール | 内容 |
|---|---|
| 窓口は院長 | スタッフが保険会社の電話で約束・回答しない。院長に引き継ぐ |
| 記録を残す | 日時・保険会社・担当者・内容・約束したことを記録（交通事故対応記録） |
| 根拠で話す | 「痛いと言っているので」ではなく、施術録の症状・経過・医師の診断で説明する |
| 書面で確認 | 打ち切り・料金・部位などの重要な話は、書面（メール・FAX）でも確認する |
| 約束しない | 「○か月で必ず治します」など結果を約束しない |

### 5-2 保険会社が見ていること【社内方針】

- 医師の診断名・整形外科への通院状況
- 事故の大きさ（車の損傷・修理費・事故状況）
- 症状の経過（良くなっているか、横ばいか）
- 通院の頻度と期間、部位数

→ 施術録に **毎回の症状と経過** を具体的に残しておくことが、保険会社の不当な打ち切り・減額に対抗するいちばんの材料になる。

## 6. 患者様への説明

### 6-1 初診時に説明すること【社内方針】

1. 一括対応なら窓口負担は原則ないこと
2. 自賠責から慰謝料・休業損害・通院交通費が出ること（C1 2-2）
3. 整形外科の受診を続けること（定期的な診察）
4. 痛み・違和感のある箇所はすべて医師にも伝えること（伝えていない部位は後から認められにくい）
5. 症状に合わせて継続して通院することが大切なこと（自己判断で中断すると後遺症のリスクがある）
6. 困ったこと（保険会社から何か言われた等）があったらすぐ相談してほしいこと

### 6-2 説明してはいけないこと

- 「通えば通うほど慰謝料が増える」などのお金を目的にした通院のすすめ（C1 6）
- 症状がない部位を医師に申告するようすすめること（C3 3）

---

## 7. まとめ（中級で必ず覚えること）

1. 請求は一括対応・被害者請求・加害者請求の 3 つ。一括がなくても被害者請求ができる。
2. 毎月、施術証明書・施術費明細書を施術録と一致させて作成する。
3. 自賠責の施術費は「必要かつ妥当な実費」。根拠は施術録。
4. 過失があっても相手の自賠責は使える（過失 70％以上は 2 割減額、100％は不可）。
5. 保険会社とのやり取りは院長が、記録を残し、根拠で話す。
6. 健保・被害者請求・人身傷害などの選択肢を説明し、決めるのは患者様。
