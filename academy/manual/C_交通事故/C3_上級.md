# C3 交通事故対応業務（上級）マニュアル

対象：C2 合格者・現院長　／　到達目標：保険会社の指示をうのみにせず、患者様の権利と施術の必要性を根拠にもとづいて守り、同時に不正やトラブルから院を守れる

> 【公的制度】＝法律・保険の決まり、【社内方針】＝当社の決まり、【要確認】＝改定で変わるため本部が最新を確認する箇所、【要記入】＝本部が社内の情報を記入する箇所

---

## 1. 「言いなりにならない」とはどういうことか【社内方針】

- 保険会社の指示は、**保険会社としての支払いの判断** であって、患者様の治療の終了や、施術の必要性を決めるものではない。
- 院長がすべきことは、保険会社と喧嘩することではなく、
  1. 施術の必要性を **施術録・医師の診断** という根拠で示す
  2. 患者様に **選択肢**（被害者請求・健保・人身傷害・弁護士相談）を正しく説明する
  3. 決めるのは患者様。院は患者様の治療を支える
- 逆に、根拠のない通院・部位の請求は、保険会社に打ち切り・減額の理由を与え、院の信用を失う。**正しい記録と適正な請求こそが、言いなりにならないための武器**。

---

## 2. よくある 3 つの指示と対応

### 2-1 「そろそろ治療終了で」「3 か月で打ち切り」「週 2 回までにしてください」

| 知っておくこと【公的制度】 | 院長の対応【社内方針】 |
|---|---|
| 一括対応の終了は、任意保険会社が立て替え払いをやめるということ。**治療の終了ではない** | 1. 施術録で症状と経過（改善しているが残っている等）を確認し、保険会社に具体的に説明する |
| 治療の必要性・症状固定を判断するのは医師 | 2. 患者様に整形外科を受診してもらい、医師の意見（治療継続の必要性）を確認する |
| 一括が終わっても、**被害者請求** で自賠責の枠内で請求できる。**健康保険**（第三者行為の届出）や **人身傷害保険** でも続けられる | 3. それでも打ち切られる場合は、患者様に選択肢を説明する（被害者請求・健保切替・弁護士相談） |
| 「○か月」という目安は保険会社の社内基準であり、法律の決まりではない | 4. やり取りはすべて記録する（日時・担当者・内容） |

> 通院頻度は **症状に応じて** 決める。症状が改善すれば頻度を減らすのは自然なこと。症状と関係なく回数を増やす・期間を延ばすのは、打ち切りの正当な理由になる。

### 2-2 「整形外科の医師の同意（許可）がないと払えません」

| 知っておくこと【公的制度】 | 院長の対応【社内方針】 |
|---|---|
| 打撲・捻挫・挫傷の柔道整復の施術に、**法律上、医師の同意は不要**（骨折・脱臼は応急手当を除き必要） | 1. 法律上は不要であることを踏まえつつ、医師の診断・意見があると施術の必要性が認められやすいことも理解する |
| ただし、保険会社が施術費の必要性・相当性を判断するとき、医師の診断・指示の有無は重視される。裁判でも医師の指示があると認められやすい | 2. 初診時から整形外科を受診してもらい、定期的な診察を続けてもらう（併院） |
| | 3. 患者様から医師に「接骨院にも通っている」ことを伝えてもらう。医師との良い関係をつくる |
| | 4. 医師が接骨院の通院に否定的な場合は、院長が MG・交通事故責任者に相談する |

### 2-3 「施術料金を健保基準に下げてください」「部位を減らしてください」

| 知っておくこと【公的制度】 | 院長の対応【社内方針】 |
|---|---|
| 自賠責の施術費は「必要かつ妥当な実費」。健保の料金表に合わせる義務はない | 1. 当社の料金基準（【要記入】）と、その施術内容を説明する |
| 部位数・料金の妥当性は、負傷の内容・医師の診断・施術の記録で判断される | 2. 部位ごとに、事故での負傷原因・医師の診断名・毎回の症状の記録があるか確認する |
| | 3. 根拠がある部位は、記録を示して説明する。根拠が弱い部位は、無理に請求しない |
| | 4. 合意できない場合は MG・交通事故責任者に相談する。患者様には被害者請求などの選択肢を説明する |

## 3. 部位の正しい扱い（最重要）

### 3-1 してよいこと【社内方針】

- 初診で、痛み・違和感のある箇所を **すべて** 聞き取り、記録する（C1 4-2）。
- 実際に症状があるのに医師の診断書に書かれていない部位があれば、患者様に「次の診察で医師にも伝えてください」と案内する。
- 事故から時間がたって出た症状は事故との関係が認められにくい。だからこそ **初診で丁寧に聞く**。

### 3-2 してはいけないこと【公的制度】【社内方針】

| してはいけない | 理由 |
|---|---|
| 症状のない部位を医師に申告するよう患者様に頼む・誘導する | 事実と違う診断・請求になり、**保険金詐欺** にあたるおそれがある。患者様も巻き込む |
| 「診断がつきやすい部位」を選んで追加する | 同上 |
| 売上のために部位数を増やす・請求単価を上げることを目標にする | 症状ではなく売上で施術を決めることになる |
| 車の損傷の大きさだけで、通院期間を先に決める | 通院期間は症状で決まる。損傷は保険会社が参考にする情報にすぎない |

> 不正が発覚すると、院・会社の信用失墜、保険会社からの返還請求、刑事事件（詐欺）、柔道整復師の免許への影響がある。**他院や過去のやり方がそうでも、当社ではしない。**

## 4. 症状固定と後遺障害

### 4-1 症状固定【公的制度】

- 治療を続けてもそれ以上良くならない状態。**判断するのは医師**。
- 症状固定後の施術費は、原則として賠償の対象外になる。残った症状は後遺障害として扱う。

### 4-2 後遺障害の認定【公的制度】【要確認】

- 医師が **後遺障害診断書** を書き、自賠責（損害保険料率算出機構）が等級（1〜14 級）を認定する。
- 申請の方法は 2 つ：任意保険会社が手続きする **事前認定**、患者様が自分で申請する **被害者請求**。
- むちうちなどで多いのは 14 級（後遺障害慰謝料は自賠責基準で 32 万円）。
- 認定には、事故直後から **継続的に整形外科を受診** していることや、一貫した症状の記録が重要。だからこそ初期からの整形外科受診と、施術録の記録が大切。

### 4-3 自賠責の調査【公的制度】

- 任意保険会社は、事故が軽微な場合などに、自賠責（損害保険料率算出機構）へ事前に支払いの可否を確認することがある。認められないと、一括対応も自賠責の支払いも受けられないことがある。
- このような場合は、患者様に弁護士への相談をすすめる（院が交渉の当事者にならない）。

---

## 5. 弁護士との関わり方【公的制度】【社内方針】

- 示談・過失割合・慰謝料額の交渉を、患者様の代わりに行えるのは **弁護士だけ**（院長・スタッフが行うと非弁行為）。
- 患者様に「弁護士に相談する方法がある」「ご自身の保険に弁護士費用特約が付いていないか確認してみては」と **情報提供** するのはよい。
- 弁護士を紹介して **紹介料・謝礼を受け取る／払う** ことは禁止（弁護士法違反のおそれ）。
- 弁護士から施術内容の照会があった場合は、患者様の同意を確認し、施術録にもとづいて回答する。

---

## 6. 広告と勧誘【公的制度】【要確認】

- 柔道整復師の広告は、法律で書ける内容が限られている（柔道整復師法）。「交通事故専門」「慰謝料が増える」などの表現は使わない。ホームページ・チラシは本部の確認を受ける。
- 「慰謝料がもらえるから通いましょう」という勧誘はしない（C1 6）。

---

## 7. 交通事故の数字の見方【社内方針】

- 交通事故の売上 ＝ 患者数 × 平均通院回数 × 平均請求単価
- 院長が **増やしてよい・増やすべき** のは **患者数**（紹介・ホームページ・整形外科との連携・当日来院につなげる電話対応）と、**途中で通院をやめてしまう患者様を減らすこと**（説明・相談対応）。
- 通院回数・請求単価は、**症状と適正な施術の結果** として決まるもの。回数・部位を増やすことを目標にしない。
- 売上・紹介数の減少の多くは、保険会社に打ち切られる・説明不足で患者様が離れることが原因。本マニュアルの対応で防ぐ。

## 8. ケーススタディ（上級試験の記述問題の例）

**ケース 1**：追突事故の患者様（通院 2 か月、首の痛みは改善傾向だが残っている）。任意保険会社から「今月末で一括対応を終了します」と院に電話があった。院長としての対応を、保険会社・患者様の両方について述べよ。

**ケース 2**：保険会社から「整形外科の医師の同意書がないと、接骨院の施術費は払えません」と言われた。患者様は整形外科に 1 回しか行っていない。院長としての対応を述べよ。

**ケース 3**：患者様の過失 80％の事故。任意保険会社から「健保対応でお願いします」と言われた。院長として患者様に説明すべきことを述べよ。

**ケース 4**：スタッフが、首だけ診断されている患者様に「腰も診断してもらえば通院期間が延ばせますよ」と言っていた。患者様は腰の痛みを訴えていない。院長としての対応を述べよ。

## 9. まとめ（上級で必ず覚えること）

1. 一括対応の終了は治療の終了ではない。被害者請求・健保・人身傷害の選択肢がある。決めるのは患者様。
2. 打撲・捻挫の施術に法律上医師の同意は不要。でも医師の診断・併院が施術の必要性の裏づけになる。
3. 自賠責の施術費は「必要かつ妥当な実費」。根拠は施術録と医師の診断。
4. 症状のない部位を申告させる・損傷規模で期間を決めるのは不正。症状を漏れなく聞いて記録するのが正しいやり方。
5. 症状固定・後遺障害の判断は医師。継続的な受診と一貫した記録が大切。
6. 示談・過失割合の交渉は弁護士だけ。紹介料のやり取りは禁止。
7. 増やすのは患者数と通院継続率。回数・部位を目標にしない。
