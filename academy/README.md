# 院長認定制度（仮称）— 研修マニュアル・試験一式

接骨院の「院長になるための資格制度」の規程・マニュアル・問題バンクをまとめたフォルダです。
**予約システム（`src/`・`xserver/`）や投稿機能とは無関係で、どのプログラムからも読み込まれません。**

## 目的

- 店舗長として必要な業務知識を「院長になってから MG が教える」のではなく、**試験に合格していなければ院長になれない** 仕組みにする。
- 交通事故患者様への対応力の底上げ、保険会社の指示をうのみにしない知識の定着により、売上・紹介数の減少を止める。

## 試験の全体像（3 分野 × 3 レベル ＝ 9 科目）

| 分野 | 下級 | 中級 | 上級 |
|---|---|---|---|
| A 管理業務（社内提出物・勤怠） | A1 | A2 | A3 |
| B 健康保険業務（申請・対応） | B1 | B2 | B3 |
| C 交通事故対応業務 | C1 | C2 | C3 |

- 一般スタッフ全員が受験対象。各分野 **下級 → 中級 → 上級の順番必須**。
- 9 科目すべてに合格した人だけが院長に任用される資格を持つ。
- 各科目 20 問・30 分、80％（16 問）以上で合格。再受験はいつでも可。
- 詳細は [00_制度規程.md](00_制度規程.md)、出題範囲は [01_科目一覧とシラバス.md](01_科目一覧とシラバス.md)。

## フォルダ構成

| 場所 | 中身 | 誰が見る |
|---|---|---|
| `00_制度規程.md` | 制度のルール（受験資格・合格基準・更新・現院長の移行） | 全員 |
| `01_科目一覧とシラバス.md` | 9 科目の出題範囲 | 全員 |
| `manual/` | 科目ごとの学習マニュアル | 全員 |
| `questions/` | 問題バンク（問題文のみ・解答なし） | **本部のみ**（出題用。受験者には本部が選んだ 20 問だけを渡す） |
| `admin_only/` | 解答・解説 | **本部のみ** |
| `admin_only/社内資料_更新提案.md` | 社内資料「院長事前研修」の直すべき点 | **本部のみ** |
| `mg/` | MG 用のヒアリングシート（ケーススタディ・現場の質問の聴取） | MG・本部 |

> 第 1 段階は文書で運用します。スタッフにはこのリポジトリを見せず、マニュアルを印刷・PDF で配布してください。
> 第 2 段階で「管理者だけが解答を見られる Web 受験画面」を予約システムとは別に作る予定です。

## 表記のルール

- **【公的制度】** 法律・通知・保険者の決まりごと。改定で変わる。
- **【社内方針】** 当社としての対応の決まり。本部が決める。
- **【要確認】** 金額・日付・回数など改定で変わりやすい／未確認の内容。本部が最新の通知で確認してから配布する。
- **【要記入】** 社内固有の情報（締切日・提出先など）。本部が記入する。
