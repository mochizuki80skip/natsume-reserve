# SNS 投稿管理 操作・設定マニュアル（接骨院版）

対象：`https://natsume.sns.hachimaru-80skip.com`（本部・各店舗のスタッフ向け）

## 1. 全体の流れ

```
本部が「定型投稿（文章）」と「画像」を登録
  ↓ 毎朝 6 時以降に自動（または「全店舗の下書きを3週間先まで作る」ボタン）
各店舗の予定枠に下書きができる（{店舗名} {エリア} などは店舗の設定で置き換わる）
  ↓ ホームの「承認待ち」で内容を確認 →「承認する」（店舗または本部）
Instagram・Google … 予定時刻に通知 →「手動投稿」画面でコピー → 各店舗の投稿ページを開いて貼り付け →「投稿した」
```

- 承認していない下書きは投稿されません。
- 内容や画像を変えると承認は外れ、もう一度「承認する」が必要です。
- Instagram・Google とも API 連携は使わない「手動投稿」の運用です。各店舗のログイン情報（ID・パスワード）と投稿ページの URL をシステムに保管しておき、そこから開いて投稿します。

## 2. 最初にやること（本部）

### 2-1. サーバーの設定を本番にする

`app/config.php` を次の状態にします（初期設定が済んでいれば）。

```php
'INSTALL_TOKEN' => '',          // 初期設定ページを無効にする
'APP_ENV' => 'production',      // エラー内容を画面に出さない
```

### 2-2. 店舗を登録する

1. `HQ` でログイン → 左メニュー（またはヘッダー）の「店舗管理」。
2. 「店舗をまとめて登録」を開き、1 行 1 店舗で貼り付けて「まとめて登録」。

```
S001,なつめ接骨院 本店,055-000-0001,初期パスワード
S002,なつめ接骨院 駅前院,055-000-0002,初期パスワード
```

- 店舗コードは予約システムと同じにします（投稿文の `{予約URL}` がその店舗の予約ページになります）。
- サンプル店舗（サンプル本店・サンプル駅前院）は削除します。
- 各店舗には「ログイン URL」`https://natsume.sns.hachimaru-80skip.com/admin/login/店舗コード` とパスワードを渡します。
- 店舗管理の一覧で、各店舗の地域・Instagram／Google の投稿の有無・ログイン情報・Google の投稿ページの登録・差し込み語の入力状況が分かります。未設定の項目は黄色で表示されます。
- 各行の「SNS設定」を押すと、その店舗の地域・差し込み語・投稿の頻度・Google の投稿ページ URL・Instagram と Google のログイン情報を設定できます。
- 一覧の「Google の投稿ページを開く」「Instagram を開く」から、その店舗の投稿ページを直接開けます。

### 2-2b. ログイン情報を保管する（本部だけ）

1. 店舗管理 → 各店舗の「SNS設定」→ 右側の「ログイン情報（本部だけが見られます）」。
2. Instagram はユーザーネームとパスワード、Google はビジネスプロフィールのオーナーの Google アカウント（メールアドレス）とパスワードを入れて「保存」。登録メール・電話（2 段階認証の受け取り先）・メモも残せます。
3. 保存したパスワードは伏せ字になり、「表示」（30 秒で自動的に隠れる）または「コピー」で取り出せます。誰がいつ表示したかが記録されます。

- 店舗アカウントではこの欄は表示されず、取り出すこともできません。
- パスワードは config.php の `SNS_SECRET` を鍵に暗号化して保存しています。`SNS_SECRET` を変えると保存済みのパスワードは読み出せなくなるので、変えないでください（変えた場合は登録し直し）。
- 「ログインURL」でその店舗のログイン URL をコピー、「名前・電話」で店舗名と電話番号を変更、「PW再設定」でパスワードを変更できます。

### 2-3. 本部の共通設定（左メニュー「接続状況」）

| 項目 | 設定 |
|---|---|
| Google は手動で投稿する（API 申請なし） | **オン** |
| 既定の頻度 | Instagram・Google それぞれの「毎週◯曜 ◯時」など。店舗ごとに変えない限りこれが使われる |
| 何日先まで下書きを作るか | 例 30〜45 日 |
| 承認待ちの通知を出す時間 | 例 24 時間前 |
| 全店共通のハッシュタグ | 店舗で指定が無いときに使う |
| 差し込み語の定義 | 店舗ごとに変える言葉を追加（例：`最寄駅` `駐車場` `院長名`）。各店舗の設定に入力欄が出る |
| 広告規制で使わない語 | 初期値あり。必要に応じて追加 |
| 文章の型 | 「本文をそのまま投稿文にする」をオフにした定型投稿で使う書き出し・締め |

保存は画面下の「共通設定を保存」。

### 2-4. 店舗ごとの頻度（左メニュー「設定」）

店舗のカードごとに、Instagram／Google に投稿するか、頻度（毎週・毎月）、曜日、時刻、運用メモを決め、右下の「保存」。

### 2-5. 店舗の詳しい設定（各カードの「詳しい設定」）

| 項目 | 内容 |
|---|---|
| 地域（エリア） | 例：沼津市。`{エリア}` に入る |
| 住所・営業時間の表記 | Instagram の `{住所}` `{営業時間}` に入る（Google には使えない） |
| ハッシュタグ | Instagram の `{ハッシュタグ}` |
| 検索キーワード | Google の `{キーワード}`（毎回入れる語＋日替わりの語） |
| 差し込み語 | 本部が定義した項目の値（例：最寄駅＝沼津駅） |
| Google の投稿作成ページの URL | 手動投稿で 1 クリックで開く。取り方は 4-2 参照 |
| Instagram のプロフィール URL | 手動投稿で開く |
| 運用メモ | 下書きを確認する人が毎回見るルール |

### 2-6. 定型投稿を登録する（左メニュー「定型投稿・ネタ」）

1. 「全店共通にする」にチェック（本部のみ）。媒体を選びます。
2. 名前（一覧用）と投稿文を書きます。投稿文には差し込み語を使えます。
   - 最初から使えるもの：`{店舗名}` `{エリア}` `{電話}` `{予約URL}` `{月}` `{キーワード}` `{営業時間}` `{住所}` `{ハッシュタグ}`
   - 本部が定義したもの：`{最寄駅}` など
3. 「◯◯店での見本」で置き換わった文章を確認して「追加」。
4. 一覧の「ライブラリから」または「アップロード」で画像を付けます（無い場合は画像ライブラリから自動で 1 枚付きます）。

**Google 用の文章のルール**：電話番号・住所・営業時間・URL は本文に入れません（`{電話}` `{住所}` `{営業時間}` `{予約URL}` `{ハッシュタグ}` は Google 用に使えません）。両方に出したい内容は Instagram 用と Google 用で別の定型投稿にします。

### 2-7. 画像を登録する（左メニュー「画像」）

「画像を選ぶ（複数可）」でまとめて登録します。JPEG に変換して長辺 1080px に縮小されます。媒体（Instagram 用／Google 用／両方）とメモを付けておくと管理しやすいです。

### 2-8. 自動処理（Cron）を登録する

サーバーパネル →「Cron設定」に、5〜10 分おきで次を登録します（`CRON_SECRET` は config.php の値）。

```
/usr/bin/curl -s "https://natsume.sns.hachimaru-80skip.com/api/cron/sns?token=CRON_SECRET" > /dev/null
```

これで「予定時刻の自動投稿」「毎朝の下書き作成」「通知」が動きます。「接続状況」の「自動処理を今すぐ実行」で手動でも動かせます。

## 3. 毎日の運用

### 3-1. 本部

1. 朝、通知（LINE またはメール）で「下書きができました」「今日の手動投稿」「承認待ち」が届きます。
2. ホームの「承認待ち」を見ます。チェック列が「OK」なら開いて内容を確認し「承認する」。まとめて承認するときはチェックを付けて「選択を承認」。
3. 「手動投稿」画面で、今日の分を上から順に処理します（4-1）。
4. 週に 1 回、「全店舗の下書きを3週間先まで作る」を押すか、毎朝の自動作成に任せます。

### 3-2. 店舗

1. 店舗のログイン URL でログイン（自店舗の分だけ表示されます）。
2. ホームで承認待ちを確認 → 直す（本文・画像）→「承認する」。
3. 「手動投稿」画面で自店舗の Google 投稿を行い「投稿した」。

### 3-3. 一斉配信（本部）

「定型投稿・ネタ」の一覧で「全店舗に一斉配信」→ 媒体と日時を選ぶと、全店舗ぶんの下書きができます。各店舗の言葉に置き換わっているので、あとは承認するだけです。

## 4. 手動投稿（Instagram・Google）

### 4-1. 手順（1 件 1〜2 分）

1. 左メニュー「手動投稿」を開く。期限切れ・今日・今後 7 日の順に並びます。
2. 「① 本文をコピーして Google を開く」を押す。本文がコピーされ、Google の画面が新しいタブで開きます。
3. Google の「最新情報を追加」に本文を貼り付け、「② 画像を保存」でダウンロードした画像を添付して投稿します。
4. 管理画面に戻り「③ 投稿した」を押す（投稿 URL があれば貼る）。状態が「投稿済み」になります。

ボタンが押せない場合は、カードの赤い注意書き（禁止語・差し込み語の未入力・GBP 掲載情報・画像なし）を「内容を直す」から直してください。

### 4-2. Google の投稿作成ページ URL の取り方（店舗ごとに 1 回）

1. その店舗のオーナー権限がある Google アカウントでログインした状態で、Google 検索で店名を検索します。
2. 検索結果に出る管理パネルの「最新情報を追加」（または「投稿を作成」）を押します。
3. 開いたページの URL をコピーし、店舗管理 → 「SNS設定」→「Google の投稿作成ページの URL」に貼って保存します。
4. 店舗管理の一覧・SNS設定・手動投稿の画面に「Google の投稿ページを開く」が表示され、1 クリックで開けるようになります。

未登録でも、手動投稿の画面から店名検索で管理パネルを開けます。

## 5. 接続（任意）

### 5-1. LINE 通知（おすすめ。通知専用の公式アカウントを 1 つ作る）

1. LINE Developers（developers.line.biz）でプロバイダーと「Messaging API」チャネルを作ります。既存の LINE 管理システムとは別の公式アカウントにすると Webhook が競合しません。
2. チャネルの「Messaging API 設定」で、チャネルアクセストークン（長期）を発行します。
3. Webhook URL に `https://natsume.sns.hachimaru-80skip.com/api/sns/line-webhook` を登録し、「Webhook の利用」をオン、「応答メッセージ」をオフにします。
4. `config.php` に入れます。

```php
'LINE_CHANNEL_ACCESS_TOKEN' => '（長期のチャネルアクセストークン）',
'LINE_CHANNEL_SECRET' => '（チャネルシークレット）',
```

5. 通知を受けたい人が公式アカウントを友だち追加し、何か 1 通送ります。
6. 「接続状況」→「LINE の通知先」にその人が表示されるので、チェックして「共通設定を保存」。「通知のテスト送信」で届けば完了です。

### 5-2. メール通知（LINE を使わない場合）

```php
'NOTIFY_EMAIL' => 'aaa@example.com,bbb@example.com',
'NOTIFY_FROM' => 'sns@hachimaru-80skip.com',
```

### 5-3. Instagram・Google の API 連携

使いません（この設置では Instagram・Google の API 連携の機能は止めてあります）。投稿はすべて手動投稿で行い、ログイン情報と投稿ページの URL を店舗ごとに保管して運用します。

## 6. 画面の一覧

| 左メニュー | 内容 |
|---|---|
| ホーム | 承認待ち・承認済み・失敗・接続状況の件数、承認待ちの一覧、「全店舗の下書きを3週間先まで作る」 |
| 店舗の下書き | 店舗ごとの投稿一覧（色の丸印と件数） |
| 手動投稿 | コピー → 開く → 画像保存 → 投稿した |
| カレンダー | 月の予定。桃＝Instagram、青＝Google。黄＝確認待ち、緑＝承認済み、灰＝投稿済み |
| 投稿一覧 | 一覧・まとめて承認／削除・手で下書きを追加 |
| 定型投稿・ネタ | 文章と画像の保管、見本、全店舗に一斉配信 |
| 画像 | 画像ライブラリ |
| 分析 | 投稿の記録。API を使わないため、いいね数などの数字は自動では取り込みません |
| 設定 | 店舗ごとの頻度・曜日・時刻・運用メモ |
| 店舗管理 | 店舗の一覧・追加、各店舗の SNS 設定とログイン情報、投稿ページへのリンク |
| 接続状況 | 本部の共通設定、通知先、自動処理の実行と記録 |

## 7. 困ったとき

| 症状 | 対応 |
|---|---|
| 承認ボタンが押せない | 変更を「保存」してから。赤い注意書き（禁止語・未入力の差し込み語・GBP 掲載情報・画像なし）を直す |
| `{最寄駅}` などが残る | その店舗の「詳しい設定」で差し込み語の値を入れ、下書きを開いて「保存」 |
| 画像なし | 「画像」にライブラリを登録する。下書きの「画像ライブラリから選ぶ」で付ける |
| 通知が来ない | 「接続状況」の LINE／メールの✓と通知先、「通知のテスト送信」。Cron が登録されているか |
| 予定時刻になっても投稿されない | 承認済みか、Cron が動いているか（「接続状況」の自動処理の記録）。Google は手動投稿 |
| 画面が白い／500 | `index.html`・`assets/`・`app/` を同じ zip から上げ直す。`config.php` は残す。`APP_ENV` を `development` にすると原因が表示される |

## 8. 更新のしかた

新しい zip を受け取ったら、次の 3 つを上書きします。`app/config.php` と `media/` は触りません。

1. `index.html`
2. `assets/` の中身（古い `index-〜.js` `index-〜.css` は削除）
3. `app/` の中身（`lib/` `handlers/` `bootstrap.php` `routes.php` `sql/` `cron/`）

上書き後に `Ctrl + F5` で開き直します。
