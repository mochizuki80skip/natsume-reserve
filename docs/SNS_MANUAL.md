# SNS 投稿管理 操作・設定マニュアル（接骨院版）

対象：`https://natsume.sns.hachimaru-80skip.com`（本部・各店舗のスタッフ向け）

## 1. 全体の流れ

```
本部が「定型投稿（文章）」と「画像」を登録
  ↓ 毎朝 6 時以降に自動（または「全店舗の下書きを3週間先まで作る」ボタン）
各店舗の予定枠に下書きができる（{店舗名} {エリア} などは店舗の設定で置き換わる）
  ↓ ホームの「承認待ち」で内容を確認 →「承認する」（店舗または本部）
Instagram（連携済みの店舗）… 予定時刻に自動投稿
Google・未連携の Instagram … 予定時刻に通知 →「手動投稿」画面でコピー → 各店舗の投稿ページを開いて貼り付け →「投稿した」
```

- 承認していない下書きは投稿されません。
- 内容や画像を変えると承認は外れ、もう一度「承認する」が必要です。
- Instagram は店舗ごとに連携すると自動投稿になります（5-3）。連携するまでは手動投稿です。
- Google の投稿は「手動投稿」の運用です（API は分析にだけ使います。5-4）。各店舗のログイン情報（ID・パスワード）と投稿ページの URL をシステムに保管しておき、そこから開いて投稿します。

## 2. 最初にやること（本部）

### 2-1. サーバーの設定を本番にする

`app/config.php` を次の状態にします（初期設定が済んでいれば）。

```php
'INSTALL_TOKEN' => '',          // 初期設定ページを無効にする
'APP_ENV' => 'production',      // エラー内容を画面に出さない
```

### 2-2. 店舗を登録する

1. `HQ` でログイン → 左メニュー（またはヘッダー）の「店舗管理」。
2. 「店舗をまとめて登録」を開き、1 行 1 店舗で貼り付けて「まとめて登録」。

```
S001,なつめ接骨院 本店,初期パスワード
S002,なつめ接骨院 駅前院,初期パスワード
```

- 電話番号は登録しません（MEO に不要で、Google の投稿文にも入れないため）。差し込み語の `{電話}` もこの設置では使いません。

- 店舗コードは予約システムと同じにします（投稿文の `{予約URL}` がその店舗の予約ページになります）。
- サンプル店舗（サンプル本店・サンプル駅前院）は削除します。
- 各店舗には「ログイン URL」`https://natsume.sns.hachimaru-80skip.com/admin/login/店舗コード` とパスワードを渡します。
- 店舗管理の一覧で、各店舗の地域・Instagram／Google の投稿の有無・Instagram の連携（自動投稿）・ログイン情報・Google の投稿ページの登録・差し込み語の入力状況が分かります。未設定の項目は黄色で表示されます。
- 各行の「SNS設定」を押すと、その店舗の地域・差し込み語・投稿の頻度・Google の投稿ページ URL・Instagram と Google のログイン情報を設定できます。
- 一覧の「Google の投稿ページを開く」「Instagram を開く」から、その店舗の投稿ページを直接開けます。

### 2-2b. ログイン情報を保管する（本部だけ）

1. 店舗管理 → 各店舗の「SNS設定」→ 右側の「ログイン情報（本部だけが見られます）」。
2. Instagram はユーザーネームとパスワード、Google はビジネスプロフィールのオーナーの Google アカウント（メールアドレス）とパスワードを入れて「保存」。登録メール・電話（2 段階認証の受け取り先）・メモも残せます。
3. 保存したパスワードは伏せ字になり、「表示」（30 秒で自動的に隠れる）または「コピー」で取り出せます。誰がいつ表示したかが記録されます。

- 店舗アカウントではこの欄は表示されず、取り出すこともできません。
- パスワードは config.php の `SNS_SECRET` を鍵に暗号化して保存しています。`SNS_SECRET` を変えると保存済みのパスワードは読み出せなくなるので、変えないでください（変えた場合は登録し直し）。
- 「ログインURL」でその店舗のログイン URL をコピー、「名前・コード」で店舗名と店舗コードを変更、「PW再設定」でパスワードを変更できます。

### 2-3. 本部の共通設定（左メニュー「接続状況」）

| 項目 | 設定 |
|---|---|
| Google は手動で投稿する（API 申請なし） | **オン** |
| 既定の頻度 | Instagram・Google それぞれの「毎週◯曜 ◯時」など。店舗ごとに変えない限りこれが使われる |
| 何日先まで下書きを作るか | 例 30〜45 日 |
| 承認待ちの通知を出す時間 | 例 24 時間前 |
| 全店共通のハッシュタグ | 店舗で指定が無いときに使う |
| 差し込み語の定義 | 店舗ごとに変える言葉を追加（例：`駐車場` `駐車場` `院長名`）。各店舗の設定に入力欄が出る |
| 広告規制で使わない語 | 初期値あり。必要に応じて追加 |
| 文章の型 | 「本文をそのまま投稿文にする」をオフにした定型投稿で使う書き出し・締め |

保存は画面下の「共通設定を保存」。

### 2-4. 配信設定：どの店舗が何曜日に投稿するか（左メニュー「配信設定」）

全店舗が 1 つの表に並びます（エリアごとにまとまって表示）。1 店舗 1 行で、次を決めて右下の「保存」を押します。

| 列 | 内容 |
|---|---|
| エリア分け | 例：浜松、沼津・三島。カレンダーのエリアのタブと、定型投稿の「対象エリア」に使われます |
| Google | チェックで投稿する。曜日のボタン（月〜日）を押して入れ外し、その下で時刻 |
| Instagram | 同じく、投稿するか・曜日・時刻 |

- 薄い色の曜日は「全店共通の既定」を表示中です。押すとその店舗だけの設定になります。「既定に戻す」で共通の既定に戻ります。
- 表の下に「曜日ごとの店舗数」が出ます（例：Google 月 8・水 8・金 8）。特定の曜日に偏っていないかの確認に使います。
- 運用メモは「カード（運用メモ）」に切り替えて入力します。

**エリアごとに曜日を分ける**（例：浜松は 月・水・金、静岡は 火・木・土）

1. 先に「店舗の一括設定」の「エリア分け」で、各店舗のエリアを決めておきます（2-5b）。
2. 「配信設定」の上のタブでエリア（例：「浜松（8 店）」）を押すと、そのエリアの店舗だけが出ます。
3. 青い枠「浜松の 8 店舗にまとめて設定」で Instagram／Google の曜日・時刻を選び、「このエリアに入れる」→ 右下の「保存」。
4. ほかのエリアも同じようにします。変更は、これから作る下書きから使われます（作成済みの下書きの日時は変わりません）。

### 2-5. 店舗の詳しい設定（各カードの「詳しい設定」）

| 項目 | 内容 |
|---|---|
| 地域（エリア） | 例：沼津市。`{エリア}` に入る |
| 住所・営業時間の表記 | Instagram の `{住所}` `{営業時間}` に入る（Google には使えない） |
| ハッシュタグ | Instagram の `{ハッシュタグ}` |
| メインキーワード・症状のキーワード | Google の投稿の「エリア＋メインキーワード」と、本文に合う症状 |
| 差し込み語 | 本部が定義した項目の値（例：駐車場＝10台あり） |
| Google の投稿作成ページの URL | 手動投稿で 1 クリックで開く。取り方は 4-2 参照 |
| Instagram のプロフィール URL | 手動投稿で開く |
| 運用メモ | 下書きを確認する人が毎回見るルール |

### 2-5b. 全店舗の設定をまとめて入力する（左メニュー「店舗の一括設定」）

各店舗の「SNS設定」の項目を、全店舗まとめて表で入力します。1 店舗 1 行で、3 つのタブに分かれています。

| タブ | 項目 |
|---|---|
| 文章の言葉（MEO） | 店舗名、エリア、エリア分け、メインキーワード、症状・施術のキーワード、本部が定義した差し込み語 |
| ハッシュタグ・投稿ページ | Instagram のハッシュタグ、Google の投稿ページ URL、Instagram のプロフィール URL |
| 投稿の有無・住所・メモ | Instagram／Google に投稿するか、住所・営業時間（Instagram の `{住所}` `{営業時間}` 用）、運用メモ |

1. 表に入力します（黄色の欄は未入力）。右下の「保存」を押します。
2. 保存すると、作成済みの下書きにも反映されます。`{エリア}` などが埋まり、手で直していない自動の下書きは今の設定で作り直されます。

**Excel でまとめて入力する**

1. 「Excel 用に書き出す（CSV）」で今の設定をダウンロードし、Excel で開いて 24 店舗分を入力します（1 行目の見出しは消さない）。
2. 見出し行を含めて表全体をコピーし、「Excel から貼り付けて入力」に貼り付けて「表に反映」→ 右下の「保存」。
3. 「投稿の有無」の列は ○ で投稿する、空で投稿しない。空のセルは変更しません。

**エリア分け**：カレンダー・設定で店舗をまとめる名前です（例：浜松、静岡、沼津・三島）。本文には出ません。同じエリアの店舗には同じ語を入れます。定型投稿の「対象エリア」にこの語を書くと、そのエリアの店舗だけに使われます。

**MEO のキーワード（Google の投稿）**

- **メインキーワード**：MEO で一番狙う語を 1 つ入れます（例：接骨院）。Google の投稿には毎回「エリア＋メインキーワード」が入ります（例：「三島市谷田で接骨院をお探しの方は、あかり接骨院へお気軽にご相談ください。」）。複数書いた場合は先頭の語を使います。
- **症状・施術のキーワード**：読点区切りで並べます（例：交通事故、ムチウチ、腰痛、子どものケガ）。本文の内容に合うものがあるときだけ 1 つ添えます（例：腰の張りの投稿 →「三島市谷田の接骨院・あかり接骨院では、腰痛のご相談も承っています。」）。合うものが無ければ入れません。
- 定型投稿の本文には `{メインキーワード}` `{症状}` も書けます。

- エリアが未入力の店舗は、下書きに `{エリア}` が残り承認できません（MEO の語が抜けたまま投稿されないため）。

### 2-6. 定型投稿を登録する（左メニュー「定型投稿・ネタ」）

1. 「全店共通にする」にチェック（本部のみ）。媒体を選びます。
2. 名前（一覧用）と投稿文を書きます。投稿文には差し込み語を使えます。
   - 最初から使えるもの：`{店舗名}` `{エリア}` `{メインキーワード}` `{症状}` `{予約URL}` `{月}` `{キーワード}` `{営業時間}` `{住所}` `{ハッシュタグ}`
   - 本部が定義したもの：`{駐車場}` など（「接続状況」の「差し込み語の定義」で追加）
3. 曜日で使い分けるときは「投稿する曜日」を選びます（例：「月_お悩み共感」は月、「水_初めての方」は水、「金_メニュー紹介」は金）。その曜日の予定にだけ使われます。選ばなければ毎日使えます。
4. 一部のエリアだけに使うときは「対象エリア」に語を入れます（例：「浜松」「沼津、三島」）。エリア分け・地域・店舗名にその語を含む店舗だけに使われます。空なら全店。
5. 「◯◯店での見本」で置き換わった文章を確認して「追加」。
6. 一覧の「ライブラリから」または「アップロード」で画像を付けます（無い場合は画像ライブラリから自動で 1 枚付きます）。

**曜日で使い分けるときの注意**：店舗の投稿の曜日も同じにしておきます（「接続状況」の「既定の頻度」で Google を「毎週 月・水・金」などにすると全店に効きます。店舗ごとに変えるときは左メニュー「配信設定」）。曜日の決まった定型投稿が無い曜日の予定には、曜日を決めていない定型投稿が使われます。

**Google 用の文章のルール**：電話番号・住所・営業時間・URL は本文に入れません（`{住所}` `{営業時間}` `{予約URL}` `{ハッシュタグ}` は Google 用に使えません）。両方に出したい内容は Instagram 用と Google 用で別の定型投稿にします。

### 2-6b. Claude で定型投稿をまとめて作って取り込む（本部）

Claude（claude.ai、MAX プランなど）で文章を作り、貼り付けて取り込みます。システムから AI を呼び出すことはないので、API の料金はかかりません。

1. 「定型投稿・ネタ」の「Claude で定型投稿を作って取り込む」を開きます。
2. テーマ（例：「秋のスポーツのケガ予防」）、本数、媒体、投稿する曜日を選びます。店舗ごとに書き分けたいときは「店舗ごとに書き分ける」にチェックします（本数 × 店舗数の量になるので、本数は 1〜2 本に）。
3. 「依頼文をコピー」を押し、claude.ai を開いて貼り付けて送ります。返答が途中で止まったら「続けて」と送ります。
4. Claude の返答を全部コピーします（返答のコピーボタンでかまいません）。返答をファイル（.txt）で受け取ったときは、「②」の「ファイルから読み込む」で複数のファイルをまとめて選べます。
5. 「②」の欄に貼り（またはファイルを読み込み）、「確認する」を押します。1 本ずつ名前・媒体・曜日・本文が表で出ます。
   - 赤（エラー）：取り込めません。Google 用に電話番号が入っている、本文が無い、など。
   - 黄（注意）：取り込めますが確認してください（禁止語、知らない差し込み語など）。
   - すでに同じ名前・同じ本文で登録済みのものは、取り込むときに飛ばされます（2 回押しても二重になりません）。
6. 「N 件を定型投稿に取り込む」を押します。取り込んだものは一覧に入り、曜日・エリアの設定もそのまま使われます。気になる文章は一覧で直します。

**エリアごとに投稿内容を分ける**（例：中部・中東部・中西部・東部）

1. 「配信設定」で、各店舗のエリア分けに「中部」「中東部」「中西部」「東部」のどれかを入れて保存します。
2. 紫の枠の「対象エリア」で「東部だけ」などを選び、「依頼文をコピー」→ claude.ai に送ります（依頼文にそのエリアの店舗の地域が入ります）。
3. 返答を取り込むときも「対象エリア」は同じままにします。「エリア：」が空のものも、そのエリアの店舗だけに使われます。
4. 4 エリア分、繰り返します。同じ曜日でも、店舗のエリアに合った定型投稿が優先して使われ、無ければ全店共通のものが使われます。

エリア分けの名前（例：東部）を対象エリアにしたときは、エリア分けがまったく同じ店舗だけに使われます（「東部」で「中東部」の店舗には使いません）。

**月ごとの投稿**：名前に「7月」のように月が入っているもの（例：`月_7月_01_夏休みの部活でのケガ`）や、「月：7」と書かれたものは、その月の予定だけに使われます。同じ月・同じ曜日に 4 本あれば、店舗ごと・週ごとに順に使われます。1 年分（12 か月 × 曜日）をまとめて取り込めます。Google の投稿の曜日（「配信設定」）を、定型投稿の曜日（例：月・水・金）と同じにしておきます。

**こつ**：曜日を選ぶと、曜日ごとに同じくらいの本数で作るよう Claude に頼みます（名前は「月_◯◯」のように曜日から始まります）。一度に 10〜15 本くらいにすると、返答が途中で切れにくくなります。

### 2-7. 画像を登録する（左メニュー「画像」）

「画像を選ぶ（複数可）」でまとめて登録します。JPEG に変換して長辺 1080px に縮小されます。媒体（Instagram 用／Google 用／両方）とメモを付けておくと管理しやすいです。

### 2-8. 自動処理（Cron）を登録する

サーバーパネル →「Cron設定」に、5〜10 分おきで次を登録します（`CRON_SECRET` は config.php の値）。

```
/usr/bin/curl -s "https://natsume.sns.hachimaru-80skip.com/api/cron/sns?token=CRON_SECRET" > /dev/null
```

これで「予定時刻の自動投稿」「毎朝の下書き作成」「通知」が動きます。「接続状況」の「自動処理を今すぐ実行」で手動でも動かせます。

## 3. 毎日の運用

### 3-1. 本部

1. 朝、通知（LINE またはメール）で「下書きができました」「今日の手動投稿」「承認待ち」が届きます。
2. 左メニュー「下書き（全店）」を開きます。全店舗の確認待ちの下書きが店舗ごとに 1 ページに並びます。
   - 店舗の絞り込み、媒体（Instagram／Google）の切り替え、「差し込み語が未入力のものだけ」で絞れます。
   - 赤い `{エリア}` などが残っている店舗は、店舗の欄の黄色い入力欄に値を入れて「保存して下書きを完成」を押すと、その店舗の下書きがまとめて埋まります。
   - 内容を確認して「承認」。問題のない下書きは「問題なしを全選択」→「選択を承認」でまとめて承認できます。
3. 「手動投稿」画面で、今日の分を上から順に処理します（4-1）。
4. 週に 1 回、「全店舗の下書きを3週間先まで作る」を押すか、毎朝の自動作成に任せます。

### 3-2. 店舗

1. 店舗のログイン URL でログイン（自店舗の分だけ表示されます）。
2. 「下書き」で自店舗の確認待ちを確認 → 直す（本文・画像）→「承認」。
3. 「手動投稿」画面で自店舗の Google 投稿を行い「投稿した」。

### 3-2b. カレンダーをエリアごとに見る（本部）

左メニュー「カレンダー」は、本部では全店舗の予定を 1 つのカレンダーで表示します。

- 上のタブでエリアを選ぶと、そのエリアの店舗の予定だけになります（例：「浜松（8 店）」）。
- タブの下に、そのエリアの投稿の曜日・時刻がまとめて出ます（例：「Google 毎週 月・水・金 10:00　8 店」）。「曜日・時刻を変える」で、同じエリアに絞った「配信設定」が開きます。
- 店舗を選ぶと 1 店舗だけになります。「この店舗の一覧・下書きの追加」から、その店舗の投稿一覧に移れます。
- 「マスの表示」で切り替えます。「内容ごと」は同じ定型投稿を使う店舗を 1 つにまとめて「名前（N 店）」で、「店舗ごと」は「時刻＋店舗名＋投稿の名前」で 1 件ずつ出ます。1 日 7 件以上は「ほか N 件」で開きます。
- **移動**：投稿をドラッグして別の日に落とすと、その日に移ります（時刻はそのまま）。「内容ごと」のまとまりをドラッグすると、その店舗分をまとめて移せます。日時だけの移動なら承認はそのままです。
- **内容・日時の変更**：投稿を押すと右にパネルが出ます。日時の変更、定型投稿の差し替え（その日に合うものが上に並びます）、承認・取り消し、削除ができます。
- **その日の投稿をまとめて**：日付の数字を押すと、その日の投稿の一覧が出ます。選んだ投稿を別の日へ移動、同じ定型投稿にそろえる、まとめて承認ができます。
- **投稿の追加**：同じパネルの「＋ この日に投稿を追加」で、媒体・時刻・定型投稿・店舗（表示中のエリア・店舗が選ばれた状態）を選んで「下書きを作る」。

### 3-2c. 下書きの内容の選ばれ方（同じ内容が並ばないように）

Google は同じ内容の繰り返しをスパムとみなすことがあるため、下書きを作るときは次の順で定型投稿を選びます。

1. その曜日・月・エリアに使えるもの（曜日の決まったものが先）
2. その店舗が最近使っていないもの
3. **同じエリア分けの店舗が前後 7 日に使っていないもの**（近くの店舗に同じ文章が並ばない）
4. **同じ日にほかの店舗が使っている数が少ないもの**
5. 全店舗を通して使われた回数が少ないもの

画像ライブラリの画像も同じ考え方で、同じエリアの店舗が前後 7 日に使った画像・同じ日にほかの店舗が使った画像を避けて付けます。定型投稿の本数（同じ月・同じ曜日の本数）が多いほど、重なりは少なくなります。

### 3-3. 一斉配信（本部）

「定型投稿・ネタ」の一覧で「全店舗に一斉配信」→ 媒体と日時を選ぶと、全店舗ぶんの下書きができます。各店舗の言葉に置き換わっているので、あとは承認するだけです。

## 4. 手動投稿（Google と、未連携の Instagram）

### 4-1. 手順（1 件 1〜2 分）

1. 左メニュー「手動投稿」を開く。期限切れ・今日・今後 7 日の順に並びます。
2. 「① 本文をコピーして Google を開く」を押す。本文がコピーされ、Google の画面が新しいタブで開きます。
3. Google の「最新情報を追加」に本文を貼り付け、「② 画像を保存」でダウンロードした画像を添付して投稿します。
4. 管理画面に戻り「③ 投稿した」を押す（投稿 URL があれば貼る）。状態が「投稿済み」になります。

ボタンが押せない場合は、カードの赤い注意書き（禁止語・差し込み語の未入力・GBP 掲載情報・画像なし）を「内容を直す」から直してください。

### 4-2. Google の投稿作成ページ URL の取り方（店舗ごとに 1 回）

1. その店舗のオーナー権限がある Google アカウントでログインした状態で、Google 検索で店名を検索します。
2. 検索結果に出る管理パネルの「最新情報を追加」（または「投稿を作成」）を押します。
3. 開いたページの URL をコピーし、店舗管理 → 「SNS設定」→「Google の投稿作成ページの URL」に貼って保存します。
4. 店舗管理の一覧・SNS設定・手動投稿の画面に「Google の投稿ページを開く」が表示され、1 クリックで開けるようになります。

未登録でも、手動投稿の画面から店名検索で管理パネルを開けます。

## 5. 接続（任意）

### 5-1. LINE 通知（おすすめ。通知専用の公式アカウントを 1 つ作る）

1. LINE Developers（developers.line.biz）でプロバイダーと「Messaging API」チャネルを作ります。既存の LINE 管理システムとは別の公式アカウントにすると Webhook が競合しません。
2. チャネルの「Messaging API 設定」で、チャネルアクセストークン（長期）を発行します。
3. Webhook URL に `https://natsume.sns.hachimaru-80skip.com/api/sns/line-webhook` を登録し、「Webhook の利用」をオン、「応答メッセージ」をオフにします。
4. `config.php` に入れます。

```php
'LINE_CHANNEL_ACCESS_TOKEN' => '（長期のチャネルアクセストークン）',
'LINE_CHANNEL_SECRET' => '（チャネルシークレット）',
```

5. 通知を受けたい人が公式アカウントを友だち追加し、何か 1 通送ります。
6. 「接続状況」→「LINE の通知先」にその人が表示されるので、チェックして「共通設定を保存」。「通知のテスト送信」で届けば完了です。

### 5-2. メール通知（LINE を使わない場合）

```php
'NOTIFY_EMAIL' => 'aaa@example.com,bbb@example.com',
'NOTIFY_FROM' => 'sns@hachimaru-80skip.com',
```

### 5-3. Instagram の自動投稿（Meta のアプリを 1 つ作る）

自社で管理しているアカウントだけに使う場合は、Meta のアプリ審査（App Review）なしで使えます（Standard Access）。連携するまでは手動投稿で運用できます。

**準備（本部で 1 回）**

1. 各店舗の Instagram をプロアカウント（ビジネス）にします（Instagram アプリ → 設定 → アカウントの種類とツール）。
2. Meta for Developers（developers.facebook.com）に本部の Facebook アカウントでログインし、「アプリを作成」→ ユースケースで「Instagram でメッセージとコンテンツを管理」を選びます。
3. アプリの「Instagram」→「API 設定（Instagram ログインによる API）」を開き、「ビジネスログインを設定」で次を登録します。
   - OAuth リダイレクト URI：`https://natsume.sns.hachimaru-80skip.com/api/sns/ig/callback`
4. 同じ画面の「Instagram アプリ ID」と「Instagram アプリシークレット」を `config.php` に入れます。

```php
'IG_APP_ID' => '（Instagram アプリ ID）',
'IG_APP_SECRET' => '（Instagram アプリシークレット）',
```

5. アプリの「アプリの役割」→「役割」→「Instagram テスター」に、24 店舗の Instagram アカウントを追加します。
6. 各店舗の Instagram で招待を承諾します（Instagram の Web 版 → 設定 → アプリとウェブサイト → テスターへの招待 →「承諾」）。

**店舗ごとの連携**

1. その店舗の Instagram にログインしたブラウザで、管理画面の 店舗管理 →「SNS設定」→「Instagram と連携する」を押します。
2. Instagram の画面で「許可」を押すと戻ってきて「連携中 @アカウント名」になります。店舗管理の一覧では「自動投稿」と表示されます。
3. それ以降、その店舗の承認済みの Instagram 投稿は、予定時刻に自動で投稿されます。画像は必須です。

- 連携は約 60 日有効で、自動処理が 30 日ごとに延長します。期限切れやパスワード変更で「要再連携」になったら、もう一度「Instagram と連携する」を押します。
- 1 つのブラウザで店舗を順に連携するときは、Instagram でログアウト → 次の店舗でログイン → 連携、の順にします（ログイン情報は「ログイン情報」欄に保管しておくと便利です）。
- 自動投稿が失敗すると「失敗」になり通知が届きます。内容を直して承認し直すか、手動投稿で対応します。

### 5-4. Google の API 連携（分析用。投稿は手動のまま）

Google の API は、数字の取り込み（分析）にだけ使います。投稿は今までどおり手動で、API から投稿されることはありません。連携すると、毎朝次のものを取り込み、「分析」で見られます。

- 表示回数（Google 検索・マップ）、電話、ルート検索、ウェブサイトのクリック、予約、メッセージ（日ごと）
- クチコミ（最新 50 件。分析の画面から返信もできます）
- 検索キーワード（月ごと。Google 検索・マップで店舗が表示されたときの語と回数。前月分まで）

**1. Google Cloud の準備（本部で 1 回）**

1. Google Cloud コンソール（console.cloud.google.com）に、24 店舗のビジネスプロフィールのオーナーまたは管理者になっている Google アカウントでログインし、プロジェクトを作成します（例：natsume-sns）。
2. プロジェクトの「ダッシュボード」の「プロジェクト情報」にある「プロジェクト番号」を控えます。
3. 「API とサービス」→「ライブラリ」で、次の 4 つを「有効にする」。
   - My Business Account Management API
   - My Business Business Information API
   - Business Profile Performance API
   - Google My Business API（クチコミ用）

**2. API の利用申請（承認まで数日〜数週間）**

1. Google の「GBP API contact form」（「Business Profile API」の「Prerequisites」のページから開けます）で、「Application for Basic API Access」を選びます。
2. 申請するメールアドレスは、ビジネスプロフィールのオーナーまたは管理者のものにします。プロジェクト番号を入れます。
3. 利用目的は「自社が運営する 24 店舗の接骨院の、ビジネスプロフィールのパフォーマンス（表示回数・検索キーワード）とクチコミを社内で分析するため。投稿の自動化はしない」のように具体的に書きます。
4. ビジネスプロフィールは、ウェブサイトなどの情報を最新にしておくと審査が通りやすくなります。
5. 承認されるまで、API の利用枠は 0 のままで、連携しても数字は取れません。承認のメールが届いてから 3 に進みます。

**3. OAuth の設定（承認後）**

1. 「API とサービス」→「OAuth 同意画面」で、ユーザーの種類を「外部」にしてアプリ名・メールを入れます。スコープは `https://www.googleapis.com/auth/business.manage` を追加します。
2. 公開ステータスを「本番環境」にします（「テスト」のままだと 7 日で連携が切れます）。連携のときに「確認されていないアプリ」と出たら、「詳細」→「（アプリ名）に移動」で進めます。
3. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」。「承認済みのリダイレクト URI」に次を入れて作成します。

```
https://natsume.sns.hachimaru-80skip.com/api/sns/google/callback
```

4. 表示されたクライアント ID とクライアント シークレットを config.php に入れて、サーバーに上書きします。

```php
'GOOGLE_CLIENT_ID' => '（クライアント ID）',
'GOOGLE_CLIENT_SECRET' => '（クライアント シークレット）',
```

**4. システムでの連携（本部で 1 回）**

1. HQ でログイン →「接続状況」→「Google ビジネスプロフィール」の「Google と連携する」。24 店舗を管理している Google アカウントで許可します。
2. 「拠点を読み込む」を押し、下の「店舗ごとの状態」の表で、店舗ごとに Google の拠点を選びます。
3. 翌朝以降、「分析」に数字が出ます（「自動処理を今すぐ実行」で、その日の取り込みを先に動かすこともできます）。Google の数字は数日遅れて確定し、検索キーワードは月単位（前月分まで）です。

## 7. 困ったとき

| 症状 | 対応 |
|---|---|
| 承認ボタンが押せない | 変更を「保存」してから。赤い注意書き（禁止語・未入力の差し込み語・GBP 掲載情報・画像なし）を直す |
| `{エリア}` などが残る | 「店舗の一括設定」で値を入れて「保存」、または「下書き（全店）」の店舗の欄で「保存して下書きを完成」 |
| 画像なし | 「画像」にライブラリを登録する。下書きの「画像ライブラリから選ぶ」で付ける |
| 通知が来ない | 「接続状況」の LINE／メールの✓と通知先、「通知のテスト送信」。Cron が登録されているか |
| 予定時刻になっても投稿されない | 承認済みか、Cron が動いているか（「接続状況」の自動処理の記録）。Google は手動投稿 |
| 画面が白い／500 | `index.html`・`assets/`・`app/` を同じ zip から上げ直す。`config.php` は残す。`APP_ENV` を `development` にすると原因が表示される |

## 8. 更新のしかた

新しい zip を受け取ったら、次の 3 つを上書きします。`app/config.php` と `media/` は触りません。

1. `index.html`
2. `assets/` の中身（古い `index-〜.js` `index-〜.css` は削除）
3. `app/` の中身（`lib/` `handlers/` `bootstrap.php` `routes.php` `sql/` `cron/`）

上書き後に `Ctrl + F5` で開き直します。
